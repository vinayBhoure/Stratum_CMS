## 1. What This Is

Stratum CMS is a developer-focused, API-first portfolio Content Management System. Two surfaces:

1. **Dashboard** — React app where logged-in users manage their portfolio content.
2. **Public API** — REST endpoints at `api.domain.com/v1/:userId/:section` that the user's own portfolio site consumes.

Stratum stores content; users bring their own portfolio frontend.

## 2. Stack

| Layer | Tech |
|---|---|
| Frontend | React + Vite + TypeScript + Tailwind + Redux Toolkit Query + Zod |
| Backend | Node + Express + TypeScript (strict) + Prisma + PostgreSQL |
| Auth | Custom JWT in httpOnly cookies + Bcrypt + PostgreSQL blacklist |
| Media | Multer → Cloudinary |
| Cache | Node Cache (in-memory, not Redis) |
| Hosting | Vercel (frontend) + Railway (backend) |
| CI/CD | GitHub Actions + Docker |

## 5. Workflow Constitution

These are non-negotiable. Violations override any temporary instruction in a prompt.

1. **Explain before writing.** Before producing any code, explain the logic in prose so Vinay can correct the approach before files are touched.
2. **Source of truth wins.** Never invent conventions. If a question can be answered by KB v2.0, API contracts, the schema, or a rule file, consult that first.
3. **One file per domain.** Controllers, services, routes, validators — never combine domains.
4. **Frontend validators mirror backend validators exactly.** Same fields, same constraints. No drift.
5. **Response envelope on every response.** `{ success, data, error, statusCode }` — no exceptions.
6. **userId is always derived from JWT** on private endpoints. Never from request body or params.
7. **Document as you build.** Every meaningful change updates `CHANGELOG.md` via the `/log-change` command.

## 7. Locked Constraints

Quick-reference for what cannot change without surfacing first.

- **Identity:** `userId` is opaque nanoid(12), generated server-side. Never derived from name or email.
- **Auth:** Custom JWT in httpOnly cookie `stratum_token`. NOT Clerk. NOT localStorage.
- **Cookies:** Prod `secure + sameSite: none`. Dev `lax + insecure`.
- **Tags:** Project-only. One system tag (`featured`). Users cannot delete system tags.
- **Skills:** Block-delete if referenced by Projects or Experience.
- **Cascade direction:** Junctions Cascade on parent, Restrict on reference (skill/tag).
- **No `tenantId` column.** Path A locked — `userId` is sufficient for isolation.
- **No forgot-password yet.** Email infra is Phase 7.
- **No rich text yet.** Markdown storage is Phase 7.
- **No PATCH yet.** PUT for updates in MVP.

## 8. How to Work in This Repo

### Built-in capabilities (auto-loaded)
- **Path-scoped rules** in `/.claude/rules/` activate based on which file is being edited.
- **Skills** in `/.claude/skills/` activate when their description matches the task.
- **Sub-agents** in `/.claude/agents/` are invoked for specialized checks (code review, doc sync, security audit, etc.).

### Commands worth knowing
- `/status` — current phase progress
- `/dev` — start both servers
- `/health-check` — verify everything connected
- `/migrate` — Prisma migration + client regen
- `/sync-validators` — check FE/BE Zod drift
- `/log-change` — append CHANGELOG + git add/commit/push
- `/log-error` — append to ERRORS.md
- `/log-decision` — append to DECISIONS.md

Full registry at `/.claude/commands/`.
